Add this PC to my Walnut

For a Walnut you already use on a Mac: this PC runs its sessions too. On the Mac, open Settings > Remote Hosts > Add a machine and copy the link.

Setup takes 5 to 10 minutes and downloads about 400 MB. If WSL is not on yet, Windows asks once for an administrator to turn it on, then for a restart.
