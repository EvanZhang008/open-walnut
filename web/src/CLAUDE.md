# web/src

Claude Code loads this file when it reads anything under `web/src/`; other agents read `AGENTS.md`.

- **Before you plan, build, test or ship anything the user can see, read
  `.claude/skills/walnut-ui-requirements/SKILL.md`**: the rules every UI change must meet, each
  with its real incident.
- Then the quick reference for this folder: `web/src/AGENTS.md` (invariants, menus and overlays),
  and the `walnut-web-frontend` skill for how the SPA works.
